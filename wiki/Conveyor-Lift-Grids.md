# Conveyor Lift Grids

Smart! can repeat Conveyor Lifts Mk.1 through Mk.6 with the height, top direction and item flow you select.

1. Select a native Conveyor Lift in the build gun.
2. Choose the first end, then set the height and top connection direction as usual.
3. Use the Smart grid controls or **K → Scaling** to repeat that selected lift.
4. Adjust spacing and transforms, then inspect the copied lifts and material quote before completing construction.

Downward lifts preserve their flow. Each copy resolves its own floor hole or existing conveyor attachment: an attachment valid for the first lift does not grant one to every copy. Native height, placement and unlock restrictions remain in force.

This repeats selected lifts. To automatically bridge the height difference between a distributor and a machine, use [Lift-assisted Auto-Connect](Lift-Assisted-Auto-Connect). For lift tails between stacked Blueprints, see [Blueprints](Blueprints).

With [Smart Camera](Smart-Camera), the automatic endpoint view helps check the selected top direction. Layout edits preserve inherited framing; restore mod/global framing if an explicit camera angle overrides the lift view.
